Import lead-router.json into n8n (Workflows > Import from file). Replace REPLACE_WITH_SHEET_ID with your Google Sheet ID (tabs: Leads, Rejected), connect Google Sheets and Gmail credentials, set the notification address, then POST a form payload {name,email,budget,message} to the webhook URL. Leads with a valid email and budget > 0 go to the sheet and trigger an alert tagged A (>= $1000), B (>= $250) or C; everything else is logged to Rejected.
