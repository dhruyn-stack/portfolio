How I built it

How does the phone part work?
A private Telegram bot (made with BotFather) sends each message to a webhook: a Google Apps Script web app.
What does the script do?
doPost(e) reads the text, adds a timestamp, and writes 01_INBOX/Raw_Note_<time>.md to a private GitHub repo through the GitHub API. The bot replies ✅ so I know it's saved.
How does it reach Obsidian?
The vault is a clone of that repo, so a git pull brings every new note in.
Where does Claude come in?
When I ask it to check the inbox, it follows a rules file in the vault: link notes instead of rewriting them, skip junk, leave thin notes for me, never add facts.
What does it cost?
Nothing. It runs on the free tiers of Telegram, Google Apps Script and GitHub.
